# Deployment Guide

## Production Deployment to Internet Computer

This document provides a comprehensive guide for deploying Terra Vedant Tech to production on the Internet Computer.

## Prerequisites

Before deploying, ensure you have the following installed:

- **Node.js** (v18 or higher) and **pnpm** package manager
- **dfx** (Internet Computer SDK) - Install via: `sh -ci "$(curl -fsSL https://internetcomputer.org/install.sh)"`
- **Git** for version control
